# Chatbot Simples com IA

**Autor:** Kaiky Yoshio Ono Marins  
**Categoria:** Python · Inteligência Artificial  
**Status:** Exercício introdutório

## Visão geral

Experimento pequeno de chatbot em Python. O exemplo envia uma mensagem inicial a um modelo Llama por meio do endpoint compatível da NVIDIA e imprime a resposta no terminal.

## O que demonstra

- Uso do SDK `openai` com um endpoint compatível.
- Definição de instruções de comportamento para o assistente.
- Envio de mensagens e leitura da resposta gerada.

## Tecnologias

- Python
- SDK `openai`
- NVIDIA NIM
- Llama 3.1 8B Instruct

## Material e execução

O código original está em [MATERIAL-ORIGINAL.txt](./MATERIAL-ORIGINAL.txt). Instale a dependência `openai` e configure uma chave de API válida localmente antes de executar. O exemplo arquivado deixa a chave vazia como placeholder.
